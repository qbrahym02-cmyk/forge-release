# Forge — منصة وكيل الذكاء الاصطناعي الشخصي 💜

> وكيل ذكاء اصطناعي شخصي يعمل على جهازك: يبرمج، يتصفح، يتحكم ببرامجك، يصنع الألعاب، يجدول مهامه، **ويركّب مونتاج فيديو احترافي — كله في الخلفية وبأمرك المباشر.**

## أحدث إصدار: v5.4.0 — إصلاحات النواة الكبرى

مراجعة معمّقة كاملة للكود أنتجت **15 إصلاحاً جوهرياً في موثوقية النواة**:

### 🔴 حماية البيانات
- **كتابة الجلسات ذرّية** (tmp + rename) — انقطاع كهرباء لم يعد يمحو المحادثات
- **إيقاف بالمنتصف لم يعد يسمّم الجلسة** — والجلسات القديمة المسمومة تُشفى تلقائياً
- **undo محمي**: الحذف قاصر على ملفات الوكيل نفسه — عملك اليدوي لا يُمس
- الضغط التلقائي لا يقطع دفعات الأدوات؛ والحذف أثناء التشغيل لا يُبعث الجلسة

### 🏁 السباقات
- **قفل عالمي واحد**: مستحيل تشغيل دورتين على نفس الجلسة (محادثة/مجدولة/مراقبة/تيليجرام)
- زر الإيقاف يوقف أي دورة من أي مصدر؛ ضغطتا Enter لا تبدءان دورتين

### 🔇 الإخفاقات الصامتة
- سقف 80 خطوة برسالة واضحة قابلة للمتابعة (كان موتاً صامتاً)
- مهلة تيليجرام توقف الوكيل فعلاً؛ ذيل SSE لم يعد يُهمل (استجابات فارغة بلا سبب — انتهى)

### 🪟 ويندوز
- **قتل شجري حقيقي** (taskkill /T) — لا خوادم يتيمة تحتل المنافذ أبداً
- UTF-8 سليم على حدود chunks (لا تشويه عربي)؛ سجل ثقة غير حساس لحالة الأحرف؛ EOL محفوظ في edit_file

### 🧠 الوكيل
- **التاريخ/الوقت في البرومبت** — «لخّص مبيعات الأمس» صارت قابلة للإجابة
- **AGENTS.md يُقرأ أخيراً** — ميزة /init أحيت من موتها
- edit_file المرن يفحص التفرّد؛ فهارس المتصفح تُمسح عند التنقل؛ بث AI EYE يتبع اللوحة

### الاختبارات
**9/9 مجموعات** رأسية، منها مجموعة **v54-verify** الجديدة (ترميم التاريخ، الجلسات الذرّية، حماية undo).

## التنزيل (Windows)
[التثبيت الكامل — أحدث إصدار](https://github.com/qbrahym02-cmyk/forge-release/releases/latest) (~111 MB)

يعمل على Windows 10/11 x64. التحديث داخل التطبيق تلقائي. Linux/macOS: من المصدر.

## من المصدر
```bash
git clone https://github.com/qbrahym02-cmyk/forge-desktop.git
cd forge-desktop && npm install
npm run dev:app
```

الكود المصدري الكامل في كل [release](https://github.com/qbrahym02-cmyk/forge-release/releases) (forge-desktop-vX-source.zip).
