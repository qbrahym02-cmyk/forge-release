# Abra Desktop — صفحة التحميل الرسمية

<div dir="rtl">

## حمّل الآن الإصدار v5.18.0 — القوة الكاملة والتحكم المطلق · ولا كود في المحادثة

**Abra Desktop** — نسخة سطح المكتب من Abra: وكيل ذكاء اصطناعي عام يعمل على جهازك مباشرة، ذكاء اصطناعي من سيرفر Abra باشتراكك (نفس حساب الموقع) أو بمفتاحك الخاص أو محلياً عبر Ollama، و**113 أداة احترافية** تعمل بلا حد زمني — متصفح يتحكم به الوكيل لحظياً، تحكم كامل بالأجهزة، **Git مدمج**، استوديو مونتاج ffmpeg، محرك ألعاب Godot، جدولة ومراقبة وتحكم عن بعد عبر Telegram.

### ما الجديد في v5.18.0؟

تنفيذ توجيه المالك: **«طوّر الأدوات إلى مستوى احترافي جداً وليكن لدى Abra قوة كبيرة وتحكم مطلق فيها» + «لا يظهر كود داخل المحادثة — الملفات تظهر كملفات والضغط عليها يفتح المحرر»**:

- ⚡ **113 أداة (+14 جديدة)** — مجموعة **Git كاملة** (status / diff / log / branches / add / commit / checkout)، **معلومات النظام** (معالج/ذاكرة/قرص/شبكة)، **قائمة العمليات**، **الحافظة** (قراءة/كتابة)، **بصمة SHA-256** للملفات، **معلومات الملفات** (حجم/تواريخ/أسطر)، و**استبدال شامل عبر الملفات** بمعاينة جافة قبل التنفيذ.
- 🎛️ **التحكم المطلق** (الإعدادات ← الأدوات) — **3 أوضاع قوة**: القوة الكاملة (كل شيء يعمل بلا بطاقات إذن للأدوات العادية)، متوازن (الافتراضي)، آمن (قراءة فقط). **مفتاح تشغيل/إيقاف لكل أداة من الـ113** يتقدم على كل الأوضاع، شارات خطورية لكل أداة (قراءة/كتابة/خطر)، و**إحصاءات استخدام حية** (عدد الاستدعاءات والفشل لكل أداة). الأداة المعطالة تُحذف من قائمة النموذج نفسها.
- 🗂️ **لا كود في المحادثة** — كل ملف يكتبه أو يعدّله Abra يظهر **بطاقة ملف** (الاسم + جديد/معدّل + +/−) والضغط عليها يفتح **محرر الكود** على الملف مباشرة. كتل الكود داخل ردود النص تتطوى لرقائق صغيرة تفتح في المحرر كعرض قراءة فقط. المحادثة نظيفة: أفكار ونتائج، والكود في مكانه الطبيعي.
- 🧪 **213 فحص واجهة + 22/22 مجموعة اختبار محرك** (شاملة الجولات الحية) · typecheck صفر · بناء نظيف بدون أي أسرار داخل الحزمة.

> **الترقية**: مستخدمو 5.6.0 حتى 5.17.0 — التطبيق يحدّث نفسه تلقائياً (فحص كل 4 ساعات) ويثبّت الترقية مكان القديم مباشرة، ولا تتأثر بياناتك المحلية. (من ثبّت v5.16.0 القديم سابقاً: أزله أولاً إن كان لا يزال موجوداً.)

### خطوات التثبيت (Windows)

1. حمّل ملف `Abra-Setup-5.18.0.exe` من الجدول أعلاه
2. انقر نقراً مزدوجاً على الملف → المثبّت يعمل تلقائياً (oneClick) — إن ظهر تحذير SmartScreen اختر «مزيد من المعلومات» ثم «تشغيل على أي حال» (لا شهادة توقيع بعد)
3. شغّل البرنامج من قائمة ابدأ → **Abra**
4. سجّل الدخول بحساب Abra (نفس حساب الموقع) — ستجد محادثاتك وموصلاتك من الويب بانتظارك
5. جرّب التحكم المطلق: **الإعدادات ← الأدوات** — بدّل أوضاع القوة وفعّل/عطّل أي أداة
