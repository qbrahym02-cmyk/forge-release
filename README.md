## حمّل الآن الإصدار v8.0.0 — حزم القدرات: 88 أداة جديدة عبر 7 حزم تخصصية

**Abra Desktop** — نسخة سطح المكتب من Abra: وكيل ذكاء اصطناعي عام يعمل على جهازك مباشرة، ذكاء اصطناعي من سيرفر Abra باشتراكك (نفس حساب الموقع) أو بمفتاحك الخاص أو محلياً عبر Ollama، و**132 أداة أساسية + 88 أداة تخصصية في 7 حزم قدرات تُحمّل بذكاء حسب مجال المهمة** تعمل بلا حد زمني — قراءة مستندات PDF/Word/Excel وتلخيصها، تحليل جداول ورسوم بيانية، بحث ومقارنة بمصادر موثقة، بريد وتقويم Outlook (قراءة فقط)، استوديو مونتاج ffmpeg، متصفح يتحكم به الوكيل لحظياً، تحكم كامل بالأجهزة، Git مدمج، جدولة ومراقبة وتحكم عن بعد عبر Telegram.

### ما الجديد في v8.0.0؟ حزم القدرات — 88 أداة جديدة تُحمّل بذكاء

توجيه المالك 2026-10-11: «لا أنصح بإضافة مئات الأدوات إلى قائمة واحدة وإرسال تعريفاتها كلها إلى النموذج في كل طلب. الأفضل إنشاء حزم قدرات مستقلة» — فصار النظام **حزم قدرات مستقلة** تُحمّل حسب المهمة:

- 🧩 **نظام الحزم (Capability Packs)** — الأدوات الأساسية (132) تبقى دائماً، و**7 حزم تخصصية بـ88 أداة جديدة** تفترضيّاً فقط عند مطابقة مجال المهمة (برمجة/بيانات/وسائط/أتمتة) أو كلماتها المفتاحية (godot، اختبر الموقع، sqlite…) — والوكيل يستطيع طلب أي حزمة في أي لحظة عبر `pack_load`. مدير الأدوات في الإعدادات يعرض الكل بتصنيفات الحزم الجديدة.
- 🛠️ **هندسة البرمجيات (17)** — كشف المشروع ولغته تلقائياً، خريطة المشروع، بحث الرموز والمراجع، مخطط الاعتماديات والدورات، تشغيل الاختبارات/البناء/فحص الأنواع/lint، إدارة خوادم التطوير، تدقيق الاعتماديات، **تشخيص الأخطاء الفوري** (20+ نمطاً مع الإصلاح)، وإصلاحات آمنة: رقعة متعددة الملفات بمعاينة، تطبيق رقع Git، مساحات عمل معزولة، واسترجاع انتقائي بنسخ احتياطية تلقائية.
- 🌐 **أتمتة متصفح أذكى (9)** — لقطة صفحة مهيكلة، إيجاد عناصر بالنص/الدور/المحدد، التقاط أخطاء console والشبكة، تحققات، **تدفقات اختبار بخطوات متتابعة مع نتيجة لكل خطوة** وتتبع JSON، فحص التنزيلات، استخراج الجداول إلى CSV، ومقارنة الصفحة قبل/بعد.
- 🖥️ **طبقة UI لسطح المكتب (7)** — قراءة شجرة عناصر واجهة النظام (UI Automation) بأسمائها وأدوارها وإحداثياتها: إيجاد أي زر أو حقل، **تدفقات أفعال موثّقة لكل خطوة**، كشف حوارات الأخطاء ونصوصها، وفحص التطبيقات المفتوحة — أتمتة البرامج بلا API (مثبّتات، برامج تصميم، أنظمة قديمة).
- 🎮 **تطوير ألعاب ثلاثي المحركات (20)** — **Godot**: فحص وتعديل المشاهد مباشرة + سجلات الأخطاء + playtest بتحقق من عقد اللعبة + لقطة إطار حية + فحص أصول مفقودة + إعدادات المشروع + أنيميشن. **Unity**: فحص المشروع، تعديل المشاهد، قوالب C#، سجل المحرر، تشغيل الاختبارات والبناء فعلياً. **Unreal**: فحص المشروع والأصول، تعديل المخططات عبر Python، السجلات، التشغيل والبناء. الحلقة الكاملة: عدّل ← شغّل ← شاهد ← أصلح.
- 🎨 **وسائط إبداعية (14)** — **Blender كامل**: مشاهد وأجسام وخامات وإضاءة وكاميرات **وتصيير يُراجَع بصرياً** — + بيانات الوسائط، استخراج الصوت، كشف مشاهد الفيديو، تفريغ صوتي محلي صادق (whisper)، تقسيم بالسكوت، فحص الصور، مزامنة وترجمة الترجمات.
- 📊 **بيانات وواجهات (16)** — **SQLite حقيقي** (استعلام/مخطط/تصدير — قراءة فقط افتراضياً)، تحليل JSON/JSONL، استنتاج وتحقق schemas، فحص OpenAPI، **اختبار سلاسل API بمتغيرات وتحقيقات**، أرشيفات zip/tar بفك آمن مضاد للهروب، إعادة تسمية دفعية، **تحليل عميق لجداول CSV** (أنواع/فارغ/تكرارات/شواذ) وتنظيفها بمعاينة — وقراءة/إنشاء PowerPoint حقيقي + جداول PDF + قراءة نص من الصور (رؤية).
- 🔁 **سير عمل قابل للاستئناف (5)** — قسّم المهمة الطويلة لخطوات بأدوات فعلية مع تحقق شرطي لكل خطوة: **التقدم يُحفظ بعد كل خطوة**، إعادة المحاولة عند الفشل، واستئناف من حيث توقفت — وكل خطوة حساسة تمر عبر **نظام الصلاحيات** كالمعتاد (بطاقات الموافقة في المحادثة).
- 🧪 **الجودة والأمان** — حزمة اختبارات جديدة **v80-unit بـ133 فحصاً** (دورة pptx كاملة، SQLite حقيقي، رفض هروب الأرشيفات، بوابات صلاحيات سير العمل) · المجموعة الكاملة **30/30** · typecheck صفر · **ALL UI CHECKS PASSED** للتطبيق الحقيقي · برهان asar وظيفي: حزم v8 السبع **تعمل من داخل الحزمة المشحونة نفسها**.

### ما الجديد في v7.2.0؟ الموصلات والمهارات صارت في سياق المحادثة — والوكلاء جاهزون فقط

توجيه المالك 2026-10-09: «1- الموصلات اجعلها تستخدم كمهاره من اجينت و لما مستخدم يظغط عليها تنضاف في محادثه و يمكن لل Agent استخدامها 2- ال Agent مخصصين انا اريد فقط الي نحن صنعناهم يعني المستخدم لا يمكنه صناعه 3- المهارات يمكن للمستخدم ان يحول اي محادثه الى مهاره او ببساطه يطلب من AI صنع مهاره او يمكن دخول لعرض مهارات و ان يصنع واحده بنفسه هناك 4- في اختيار مجلد مشروع للبدء قائمه منسدله فيها مجلدات سابقه 5- لما المستخدم يختار واحد من Agent مخصصين يظهر في اطار حقل برومت انه يستخدمه»:

- 🔌 **الموصلات تُستخدم كمهارة** — اضغط أي موصل في ＋ ← الموصلات فيتثبت في **سياق المحادثة**: الوكيل **يستدعيه مباشرة عبر http_request في كل رد** (حتى 4 موصلات) والمفتاح يُحقن تلقائياً عند نداء الخدمة — ولا يدخل المفتاح نصَّ البرومبت أبداً. التثبيت مرئي بالكامل: ✓ زمردية على الصف + **رقاقة زمردية على حافة حقل الإدخال** باسم الموصل (وزر ✕ يفكها فوراً).
- 🤖 **الوكلاء المخصصون = الجاهزون فقط** — ثمانية وكلاء من صنعنا (مطور تطبيقات · مطور ألعاب · محلل أسواق · مصمم واجهات · كاتب محتوى · خبير تسويق · محلل بيانات · مونتير فيديو) — **إنشاء الوكلاء أُغلق نهائياً** بأمر المالك: صفحة الوكلاء صارت معرضاً للقراءة والتشغيل فقط، ونموذج الإنشاء والتعديل والحذف أُزيل بالكامل.
- 🪄 **صناعة المهارات بثلاث طرق** — (1) زر «مهارة» في الشريط العلوي لأي محادثة **يحوّل خلاصتها إلى مهارة** قابلة للتعديل قبل الحفظ · (2) ببساطة **اطلب من الوكيل** «اصنع لي مهارة» فيستخدم أداته الجديدة `skill_create` · (3) صفحة المهارات فيها محرر **«مهارة جديدة»** يدوي كامل — كلها تُكتب في `.forge/skills` وتظهر فوراً قابلة للتثبيت من قائمة ＋ في أي محادثة (مع زر حذف للمهارات التي صنعتها بنفسك).
- 📂 **مجلدات سابقة عند البدء** — زر «اختر مجلد مشروع للبدء» صار **قائمة منسدلة** تعرض مجلداتك الأخيرة (حتى 8، مرتبة بالأحدث استخداماً مع وقت آخر عمل) + «اختر مجلداً آخر…» للمنتقي الأصلي — افتح مشروعك السابق بنقرة واحدة بلا طقوس الاختيار من جديد.

2. انقر نقراً مزدوجاً على الملف → المثبّت يعمل تلقائياً (oneClick) — إن ظهر تحذير SmartScreen اختر «مزيد من المعلومات» ثم «تشغيل على أي حال» (لا شهادة توقيع بعد)
3. شغّل البرنامج من قائمة ابدأ → **Abra**
4. سجّل الدخول بحساب Abra (نفس حساب الموقع) — ستجد محادثاتك وموصلاتك من الويب بانتظارك
5. جرّب الجديد: اطلب مهمة برمجية («ابن لي مشروع ويب») وستجد أدوات هندسة البرمجيات الجديدة تُحمَّل تلقائياً في المدرج — ثم من الإعدادات ← الأدوات رأِد الحزم السبع وأدواتها الـ88 بتصنيفاتها الجديدة، واطلب من الوكيل أيّها في أي لحظة بـ pack_load
