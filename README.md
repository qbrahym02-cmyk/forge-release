# Forge — منصة وكيل الذكاء الاصطناعي الشخصي 💜

> وكيل ذكاء اصطناعي شخصي يعمل على جهازك: يبرمج، يتصفح، يتحكم ببرامجك، يصنع الألعاب، يجدول مهامه، **ويركّب مونتاج فيديو احترافي — كله في الخلفية وبأمرك المباشر.**

## أحدث إصدار: v5.1.0 — تحصين أمني شامل + جسر MCP حقيقي

إصدار ناتج عن **تدقيق أمني كامل** للمشروعين (سطح المكتب والويب): 8 إصلاحات، صفر حذف، كل الاختبارات خضراء (41/41 أمني + 14/14 MCP + 68/68 رندر حي).

### أهم ما تغيّر في v5.1.0
- 🔒 **الوضع البعيد آمن افتراضياً**: التحكم عن بُعد (تيليجرام) ومراقِبات المجلدات كانت تعمل بصلاحيات كاملة دون سؤال — الآن الوضع الافتراضي قراءة فقط (وضع التخطيط)، والتشغيل الكامل خيار صريح
- 🔑 **مفتاح مزوّدك (BYOK) لا يغادر العملية الرئيسية**: يعود للواجهة مقنّعاً فقط
- 🧿 **تنزيل ffmpeg موثّق رقمياً**: URL ثابت الإصدار + تحقق SHA-256 إجباري + رفض صفحات HTML — لا يُنفّذ ملف غير مُتحقق منه أبداً
- 🔌 **جسر MCP حقيقي**: أدوات خوادم MCP تظهر للوكيل بمخططاتها الحقيقية وتُنفّذ عبر stdio مع بوابة صلاحيات (v5.0 ادّعت ذلك ولم تنفّذه — الآن مُختبر فعلياً)
- 🪟 إغلاق ثقب حساسية حالة الأحرف في حدود المسارات على Windows
- 🔍 157 حالة ابتلاع صامت للأخطاء صارت قابلة للتشخيص (FORGE_LOG_DEBUG)
- 🧪 أمر `npm test` موحّد يشغّل كل الـ suites
- 📁 صلاحيات 0600 لكل الملفات الحساسة محلياً

## التنزيل (Windows)
[التثبيت الكامل — أحدث إصدار](https://github.com/qbrahym02-cmyk/forge-release/releases/latest) (~111 MB)

يعمل على Windows 10/11 x64. التحديث داخل التطبيق تلقائي. Linux/macOS: من المصدر.

## من المصدر
```bash
git clone https://github.com/qbrahym02-cmyk/forge-desktop.git
cd forge-desktop && npm install
npm run dev:app
```

الكود المصدري الكامل في كل [release](https://github.com/qbrahym02-cmyk/forge-release/releases) (forge-desktop-vX-source.zip).
