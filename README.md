# Abra Desktop — صفحة التحميل الرسمية

## حمّل الآن الإصدار v6.2.0 — صندوق أكبر + «ماذا تريد أن تنجز؟» + رقائق أنواع المهام

**Abra Desktop** — نسخة سطح المكتب من Abra: وكيل ذكاء اصطناعي عام يعمل على جهازك مباشرة، ذكاء اصطناعي من سيرفر Abra باشتراكك (نفس حساب الموقع) أو بمفتاحك الخاص أو محلياً عبر Ollama، و**121 أداة احترافية** تعمل بلا حد زمني — قراءة مستندات PDF/Word/Excel وتلخيصها، تحليل جداول ورسوم بيانية، بحث ومقارنة بمصادر موثقة، بريد وتقويم Outlook (قراءة فقط)، استوديو مونتاج ffmpeg، متصفح يتحكم به الوكيل لحظياً، تحكم كامل بالأجهزة، Git مدمج، جدولة ومراقبة وتحكم عن بعد عبر Telegram.

### ما الجديد في v6.2.0؟

توجيه المالك: صندوق الإدخال كان صغيراً، والعنوان يعود ليسأل عن **المهام**، مع **رقائق أنواع مهام** بنفس أسلوب رقائق البناء المحبوبة:

- 📝 **صندوق إدخال البرومت أكبر بمرتين تقريباً** — الارتفاع الأدنى 72 ← 132 بكسل + خط أكبر (16px) وحشو أوسع: مساحة مريحة لكتابة المهمة كاملة من أول مرة (ويتمدد تلقائياً حتى 300px عند الحاجة).
- ❓ **العنوان يسأل «ماذا تريد أن تنجز؟»** بدل «تبني؟» — الصفحة الرئيسية صياغة مهام أولاً، وبرمجة التطبيقات أحد المجالات لا الافتراض.
- 🎯 **رقائق أنواع المهام (جديدة)** — صف جديد بنفس أسلوب الرقائق الكلاسيكية تماماً: **بحث · مستندات · بيانات · بريد · أتمتة · وسائط · كتابة · برمجة** — انقر رقيقة (تظهر عليها ✓) ثم اكتب مهمتك؛ **اختيارك يثبّت مجال الجلسة للوكيل** فيعمل بمنهجية ذلك المجال وأدواته من أول رسالة (وترى المجال في شريحة المجال داخل المحادثة).
- 🏗️ **رقائق البناء الثماني الكلاسيكية تبقى** — موقع · تطبيق جوال · تطبيق ويب · لعبة · لوحة تحكم · متجر · معرض أعمال · صفحة هبوط (تبادئ الرسالة بنوع ما تبنيه) — والاختيار بين المجموعتين متبادل: النقرة الأخيرة هي الفاصلة.
- 🏷️ **تسميتان صغيرتان** فوق كل صف («أنواع المهام» / «أنواع البناء») — وضوح بلا حاجة لتجربة.

- 🏠 **الرئيسية الكلاسيكية** — العنوان بتدرجه الأصلي، ورقائق البناء الثماني الملونة (اختيار/إلغاء بنقرة مع ✓ وبادئة تلقائية للرسالة)، وزر «+ اختر مجلد مشروع للبدء».
- 📎 **المرفقات من أول رسالة** — زر المشبك + السحب والإفلات + اللصق؛ الملفات تصل الوكيل في `uploads/` والصور يراها نموذج الرؤية مباشرة.
- 🧭 **موجّه المهام وشريحة المجال** — منهجية الـ6 خطوات + شريحة المجال القابلة للتغيير بنقرة.
- 🗂️ **مساحة المهام التلقائية** — لا حاجة لاختيار مجلد قبل أي مهمة (واختيار المجلد يبقى للمشاريع).

<details>
<summary><b>سجل التغيير الكامل لـ v6.0.0 (تحول «أنجز لي مهمة») — لا يزال سارياً بالكامل</b></summary>

- 📎 **مرفقات من أول رسالة** — ملفات وصور وجداول وصوت (اختيار من الجهاز أو سحب وإفلات أو لصق)؛ تصل الوكيل في `uploads/` ويقرأها بأدواته، والصور يراها نموذج الرؤية مباشرة.
- 🗂️ **مساحة مهام تلقائية** — لم تعد بحاجة لاختيار مجلد قبل أي مهمة: مساحة العمل تنشأ تلقائياً (واختيار مجلد مشروع يبقى متاحاً).
- 📄 **قراءة المستندات (3 أدوات)** — `pdf_read` (استخراج نصي حقيقي مع فشل صادق للملفات الممسوحة ضوئياً) · `docx_read` لمستندات Word · `xlsx_read` لجداول Excel — بلا اعتماديات وبلا إنترنت.
- 📊 **تحليل البيانات (3 أدوات)** — `csv_read` (كشف الفاصل تلقائياً) · `csv_analyze` (min/max/mean/median/unique/missing) · `chart_make` لرسوم SVG (bar/line/pie/scatter).
- 📧 **بريد وتقويم Outlook (أداتان)** — `office_outlook_inbox` و `office_calendar_list`: قراءة فقط بلا أي أثر؛ أي إرسال يتطلب إذناً **مع معاينة كاملة** (إلى/الموضوع/النص).
- 🧠 **ذاكرة اختيارية منضبطة** — لوحة كاملة في **الإعدادات ← الذاكرة**: اعرض وعدّل واحذف أي سطر أو أوقف الذاكرة كلياً؛ المفاتيح وكلمات المرور تُرفض تلقائياً.
- 🔐 **صلاحيات أوضح** — **مرة واحدة / لهذه الجلسة / لهذا المشروع** + **معاينة العواقب** (الرسالة كاملة قبل الإرسال، المسار قبل الحذف، حقول النموذج).
- 📋 **بطاقة «ملفات هذه الجولة»** — ما قرأه الوكيل وما أنشأه وما نقله وما حذفه في نظرة واحدة.

### خطوات التثبيت (Windows)

1. حمّل ملف `Abra-Setup-6.2.0.exe` من الجدول أعلاه
2. انقر نقراً مزدوجاً على الملف → المثبّت يعمل تلقائياً (oneClick) — إن ظهر تحذير SmartScreen اختر «مزيد من المعلومات» ثم «تشغيل على أي حال» (لا شهادة توقيع بعد)
3. شغّل البرنامج من قائمة ابدأ → **Abra**
4. سجّل الدخول بحساب Abra (نفس حساب الموقع) — ستجد محادثاتك وموصلاتك من الويب بانتظارك
5. جرّب الرئيسية الجديدة: صندوق أكبر، رقائق أنواع المهام فوق رقائق البناء — انقر «بحث» مثلاً ثم اكتب ما تريد معرفته، أو أرفق ملفاً بزر المشبك مباشرة
