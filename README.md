# Forge — منصة وكيل الذكاء الاصطناعي الشخصي 💜

> وكيل ذكاء اصطناعي شخصي يعمل على جهازك: يبرمج، يتصفح، يتحكم ببرامجك، يصنع الألعاب، يجدول مهامه، **ويركّب مونتاج فيديو احترافي — كله في الخلفية وبأمرك المباشر.**

## أحدث إصدار: v5.5.0 — «الدماغ»: وكلاء فرعيون، ذاكرة، وتكلفة أقل بـ 80%

بعد v5.4 التي أصلحت يدي الوكيل — v5.5 تُرقّي **دماغه**. **98 أداة** (+17) وكل الاختبارات خضراء (15/15 مجموعة، ~620 فحصاً جديداً).

### 💰 التخزين المؤقت للبرومبت
نفس المهمة بربع الفاتورة: بادئة مستقرة + بصمات تخزين لكل عائلة مزوّد — تكلفة الدورات الطويلة تنهار، والدورة لا تنكسر أبداً بسبب التحسين.

### 👥 الوكلاء الفرعيون (Task)
وكيل ابن **explore** قرائي يبحث ويلخّص بلا بطاقات؛ **general** بكل الأدوات عبر محرك الصلاحيات؛ ومهام **خلفية** (task_spawn/output/list/stop — حتى 3 متزامنة) تُقتل فوراً بإجهاض الأب.

### 🧠 الذاكرة الدائمة + 🎨 المهارات
`memory_append` يكتب في `.forge/memory.md` ويُحقن في كل جلسة قادمة — وكيلك يتعلّم مشروعك. ومهارات مدمجة (مونتاج TikTok، Godot، كشط ويب، محتوى عربي، خبير ويندوز) + مهارات مشروعك في `.forge/skills/` — والبرومبت الأساسي نحف.

### 🔍 LSP-lite + 🔎 المفاجآت
تشخيصات **tsserver/pyright الحقيقية** داخل نتيجة التعديل نفسه. وبحث **Ctrl+K** عبر كل الجلسات، **عناوين تلقائية**، زر **«أكمل»** عند سقف الـ80، وإشعارات **Windows Toast** للمهام الخلفية.

### 🛡️ التحصين الصامت
SHA-256 لتنزيلات **Godot** (مثبّت ببصمات حقيقية) + هاش التحديث يظهر قبل التثبيت + **safeStorage** لمفاتيح BYOK + قائمة حظر للأوامر المدمّرة + env_read بإذن.

### ⚡ 17 إصلاح أداء/موثوقية من مراجعة المستوى 0.5
بث مجمع (نهاية البث التربيعي) · لقطة في worker · LCS مسقوف · CDP يُعاد ربطه للقراءة · I/O غير متزامن · فوترة idempotent · إعادة إصدار grant تلقائية · إخلاء live map · سقف 400 رسالة · once_at نظيف · «كل يومين» بلا انجراف · المراقبون يكتبون داخل جذرهم · i18n منظّف (78 ternary).

### 🧪 معاينة الاحتكار
**ماكرو تسجيل البشر** (سجّل → أعد → جدوِل) و**Office/COM** (Word/Excel/Outlook عبر PowerShell) — MVPs أولية.
