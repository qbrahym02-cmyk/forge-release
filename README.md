# Forge — منصة وكيل الذكاء الاصطناعي الشخصي 💜

> وكيل ذكاء اصطناعي شخصي يعمل على جهازك: يبرمج، يتصفح، يتحكم ببرامجك، يصنع الألعاب، يجدول مهامه، **ويركّب مونتاج فيديو احترافي — كله في الخلفية وبأمرك المباشر.**

## أحدث إصدار: v5.3.0 — الأيدي الكاملة + محرك المتصفح اللحظي

ترقيتان كبيرتان في إصدار واحد (من 5.1.0 مباشرة): **81 أداة** بدل 68، وكل الاختبارات خضراء (8/8 مجموعات، منها 100 اختبار v5.3 جديد).

### ⚡ v5.2 — محرك المتصفح اللحظي (صفر تأخير)
- **قناة CDP مباشرة**: نقرة **1–2ms** (كانت ~500ms)، كتابة **2–8ms**، قراءة **3–4ms**، لقطة **0ms** من إطار مخبأ (كانت 200–500ms)
- **AI EYE**: عين الوكيل الحية — بث مباشر من الصفحة يظهر كلوحة عائمة في التطبيق، والوكيل يرى اللقطات فوراً بلا كلفة التقاط
- **العنونة بالفهرس** (element_index) + محددات أمتن + كتابة آمنة للأُطر (React/Vue)
- edit_file بمطابقة مرنة + replace_all، وsearch_text بـ ripgrep

### 🖐️ v5.3 — الأيدي الكاملة (13 أداة جديدة)
- **browser_hover / select / hotkey / drag / history** — تحويم، قوائم منسدلة، تركيبات مفاتيح (ctrl+a، alt+f4)، سحب متدرّج حقيقي، تنقّل — كلها لحظية
- **browser_windows + browser_switch** — تعدد نوافذ حقيقي (المنبثقات وشاشات OAuth) وشارة «× N» في AI EYE
- **create_dir / delete_path / move_path / copy_path** — عمليات الملفات الناقصة ببوابة صلاحيات وحماية جذر المشروع
- **الخلفية الحقيقية**: run_command بـ background:true يعيد pid فوراً ويُبقي خوادم dev حية — shell_output لقراءة الخرج و shell_kill للإيقاف (لا عمليات يتيمة)
- **readPage أغنى**: قيم الحقول + خيارات القوائم + حالات مربعات الصح قبل ملء أي نموذج

### التاريخ المختصر
- v5.1 — تحصين أمني شامل + جسر MCP حقيقي (اختبار أمني كامل، 8 إصلاحات)

## التنزيل (Windows)
[التثبيت الكامل — أحدث إصدار](https://github.com/qbrahym02-cmyk/forge-release/releases/latest) (~111 MB)

يعمل على Windows 10/11 x64. التحديث داخل التطبيق تلقائي. Linux/macOS: من المصدر.

## من المصدر
```bash
git clone https://github.com/qbrahym02-cmyk/forge-desktop.git
cd forge-desktop && npm install
npm run dev:app
```

الكود المصدري الكامل في كل [release](https://github.com/qbrahym02-cmyk/forge-release/releases) (forge-desktop-vX-source.zip).
