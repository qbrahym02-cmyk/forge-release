# Forge — منصة وكيل الذكاء الاصطناعي الشخصي 💜

> وكيل ذكاء اصطناعي شخصي يعمل على جهازك: يبرمج، يتصفح، يتحكم ببرامجك، يصنع الألعاب، يجدول مهامه، **ويركّب مونتاج فيديو احترافي — كله في الخلفية وبأمرك المباشر.**

## أحدث إصدار: v5.0.0 — استوديو المونتاج

**الوكيل صار مونتيراً محترفاً:** قل «اعمل مونتاج احترافي لهذه المقاطع مع الموسيقى» فيفحص المقاطع، يختار الانتقالات السينمائية (38 نوعاً)، يكتب عناوين متحركة (العربية تعمل بشكل صحيح)، **يقص على ضربات الموسيقى** (تحليل إيقاع محلي — BPM والضربات)، يدرّج الألوان سينمائياً، يضع الموسيقى مع خفض تلقائي، ويصدّر للمنصة المناسبة (تيك توك 9:16 / يوتيوب / مربع). كله في الخلفية مع شريط تقدم حي في المحادثة — لا برنامج مونتاج، لا نافذة محرر.

### ماذا يشمل v5.0.0
- 🎬 استوديو مونتاج ffmpeg كامل (14 أداة) — يعمل في الخلفية ويبدأ فقط عندما يستدعيه الوكيل
- 🎵 مزامنة صوت-فيديو: كشف الإيقاع + القص على الضربة + خفض تلقائي (ducking)
- ✍️ موشن جرافيك: نصوص متحركة بـ 10 حركات، عربية RTL سليمة
- 📱 تحويل عمودي 9:16 بتعبئة blur لتيك توك/ريلز/شورتس
- 🗑️ حذف خزنة البيانات كلياً (بطلب المستخدم)
- 📱 تحكم عن بعد من الهاتف (تيليجرام): أرسل المهمة من أي مكان فتُنفّذ هنا
- 👁️ وضع المراقبة: مجلدات توقظ الوكيل عند التغيير
- 🦙 Ollama محلي: عمل تلقائي دون إنترنت عند توفر الخادم المحلي
- 🔌 دعم MCP: خوادم أدوات خارجية توصّل نفسها بالوكيل
- 68 أداة إجمالاً

## التنزيل (Windows)
[التثبيت الكامل — أحدث إصدار](https://github.com/qbrahym02-cmyk/forge-release/releases/latest) (~111 MB)

يعمل على Windows 10/11 x64. التحديث داخل التطبيق تلقائي. Linux/macOS: من المصدر.

## من المصدر
```bash
git clone https://github.com/qbrahym02-cmyk/forge-desktop.git
cd forge-desktop && npm install
npm run dev:app
```

الكود المصدري الكامل في كل [release](https://github.com/qbrahym02-cmyk/forge-release/releases) (forge-desktop-vX-source.zip).
