## 🖥️ ما هو Forge Desktop؟

وكيل بناء مواقع وتطبيقات بالذكاء الاصطناعي يعمل على جهازك:

- **العقل في السيرفر**: نماذج الذكاء الاصطناعي تعمل من سيرفر Forge باشتراكك — لا تحتاج مفاتيح API.
- **الأدوات على جهازك**: قراءة/كتابة الملفات وتشغيل الأوامر تحدث محلياً في مجلد مشروعك، بلا حد زمني وبموافقتك على كل عملية حساسة.
- **واجهة Forge Web** نفسها: محادثات، خطوات وكيل ملوّنة، فروقات الملفات، ورموز الرصيد.

## 🔐 الخصوصية

- مجلد مشروعك لا يغادر جهازك — الوكيل يعمل عليه محلياً.
- كل «موافقة» تصدر منك أنت: سماح / سماح دائماً / رفض لكل عملية كتابة أو أمر.
